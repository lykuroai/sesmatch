# ローカルサーバ 参考実装（lykuro-connector）

SESマッチングプラットフォーム（ses.lykuro.ai、以下「親サーバ」）と連携する
**ローカルサーバ**の参考実装です。

自社環境内で案件・人材書類を収集し、**自社契約のLLM**で構造化してローカルに保管します。
データは自社に残り、**商談を始めたい1件だけ**を「公開送信」で親サーバへ登録・公開できます。
親サーバの公開案件・公開人材の検索と、そこからの**人材提案・案件紹介**（商談の申込み）も
ローカル管理画面から行えます。

- 通信は親サーバ・LLM APIへの**アウトバウンドHTTPSのみ**（受信ポートの外部開放は不要）
- 管理画面は `http://127.0.0.1:8787`（既定）。**インターネットに公開しないでください**
- 商談申込み後の承認・面談・成約は親サーバのWebコンソールで行います

## 動作の流れ

```
管理画面の「ファイルを取込」でアップロード・「テキスト貼り付け」で本文を貼り付け、
または 受入/案件/・受入/人材/ にファイルを置く
  → テキスト抽出（OCRなし） → PII匿名化（ローカル処理） → 自社LLMで構造化
  → 在庫/ に保存（原本 + 抽出JSON）… 管理画面に一覧表示

管理画面で「公開送信」
  → 抽出内容を確認・修正（人材は氏名・所属の入力が必要）
  → 親サーバへ構造化データとして登録され、そのまま企業間公開される
  ※ 人材の本人同意は登録時に自動記録されます（同意日=登録日）。
    事前に本人から公開の同意を得たうえで送信してください

管理画面の「親サーバ検索」
  → 他社の公開案件・公開人材を検索（匿名情報のみ表示）
  → 公開案件へ自社人材を「人材提案」／公開人材へ自社案件を「案件紹介」
  → 以後の商談（承認・面談・成約）は親サーバのWebコンソールで進める
```

必要なAPIトークンのスコープは「**ローカルサーバ連携**（取込・公開送信・検索・提案）」です
（親サーバの 設定 → APIトークン から発行）。

## かんたんインストール

事前に Node.js 20 以上（[nodejs.org](https://nodejs.org/ja) のLTS版）をインストールしてください。

- **Windows**: [install.bat](https://raw.githubusercontent.com/lykuroai/lykuro-connector/main/install.bat) を右クリック→「名前を付けて保存」でダウンロードして実行。
  `%USERPROFILE%\lykuro-connector` に導入され、設定ファイルがメモ帳で開きます。以後は `start.bat` で起動
- **Linux / macOS**:

```bash
curl -fsSL https://raw.githubusercontent.com/lykuroai/lykuro-connector/main/install.sh | bash
```

再実行すると最新版へ更新されます（`config.json`・`data/` は保持されます）。

## 手動セットアップ

1. Node.js 20 以上をインストールし、依存パッケージを導入

```bash
npm install
```

2. `config.example.json` を `config.json` にコピーして編集

| 設定 | 内容 |
|---|---|
| `parent.token` | **推奨**。親サーバのコンソール「会社マイページ → APIトークン」で発行（スコープ: 取込のみ） |
| `parent.email` / `password` | トークンを使わない場合の暫定認証。環境変数 `SES_PARENT_PASSWORD` の利用を推奨 |
| `llm.baseUrl` / `apiKey` / `model` | 自社契約のOpenAI互換API。キーと費用は自社負担。例: AI Gateway（`https://api.lykuro.ai/v1` + `deepseek/deepseek-v4-flash`）、OpenAI（`https://api.openai.com/v1` + `gpt-4o-mini`）、社内のOllama等 |

**AI Gateway（api.lykuro.ai）のAPIキー取得方法**:
[https://app.lykuro.ai/](https://app.lykuro.ai/) でアカウント登録し、ログイン後の画面からAPIキーを発行して
`llm.apiKey` に設定してください（`llm.baseUrl` は `https://api.lykuro.ai/v1` のまま）。
複数のAIモデルをひとつのAPIキーで利用できます。

`config.json` には秘密情報が入ります。ファイル権限を制限してください（Linux: `chmod 600 config.json`）。

3. 起動

```bash
npm start                # ./config.json を使用
node local-server.mjs /path/to/config.json
```

ブラウザで `http://127.0.0.1:8787` を開くと在庫一覧が表示されます。
常時稼働は systemd（Linux）またはタスクスケジューラ（Windows）に登録してください。

## 対応ファイル形式

テキスト (.txt .csv .md) / Word (.docx) / Excel (.xlsx .xls) / テキスト層のあるPDF。

**画像・スキャンPDFは非対応**（OCRを搭載していません）。それらは親サーバの取込パネルから
直接取り込んでください（親側でOCRされます）。

## セキュリティ・データの取り扱い

- **LLMへは匿名化済みテキストのみ送信します**。氏名・連絡先・企業名等はローカルの正規表現で
  トークン化し、匿名化検査で残存が疑われる場合はLLM送信を中止します。
  匿名化はベストエフォートであり、自社契約LLMへの送信は自社のデータ取扱方針に従ってください。
- ローカル在庫（原本・抽出JSON）の管理・バックアップ・アクセス制御は**自社の責任**です。
  プラットフォームの保存期限・本人削除請求の仕組みはローカル複製には及びません。
- 管理画面に認証はありません。`host` は既定の `127.0.0.1` のまま使うか、
  社内LANに限定してください。

## 制限事項

- 人材は1ファイル=1名です。案件は親サーバ送信後に親側で複数件自動分割されます。
- ローカルの抽出結果は自社の参考データです。親サーバへ送信すると親側で改めて正規の解析・
  人手確認が行われ、以後は親サーバ側のデータが正になります（ローカルとの同期は行いません）。
- 送信は1件ずつの明示操作です（自動一括送信はしません）。
